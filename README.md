# Teaboom Product Card

Тестовое задание на позицию HTML-верстальщика / Frontend-верстальщика.

Реализована адаптивная карточка товара «Ананасовый улун» для интернет-магазина Teaboom.

## Demo

[Открыть опубликованную страницу](https://peccopa.github.io/teaboom-product-card/)

## Реализовано

- адаптивная вёрстка для desktop, tablet и mobile;
- семантический HTML5;
- Flexbox и CSS Grid;
- выбор фасовки;
- динамическое изменение:
  - цены;
  - старой цены;
  - артикула;
  - активного состояния фасовки;

- hover и focus-visible состояния;
- доступность интерактивных элементов;
- без использования frontend-фреймворков и UI-библиотек.

## Технологии

- HTML5
- CSS3
- JavaScript
- Vite

## Запуск

Установить зависимости:

```
npm install
```

Запустить dev-сервер:

```
npm run dev
```

Собрать production-версию:

```
npm run build
```

## Источник

В качестве основы использована информация и изображение товара с сайта Teaboom.
